## 大块(核心能力)

### ✅ #1 日志保留/裁剪
`request_logs` 是日志表(硬删)。按天清理(默认 3 天)+ 每 `(group,action,client)` scope 只留最新 100 条(窗口函数),挂现成 5min 维护 worker(`retention-sweep`)。阈值走 zod 配置。
> **聚合表按天清理**(`AGGREGATE_RETENTION_DAYS`,§2.8 item 3)暂缓 → 并入 #3(表还没建)。

### 🚧 #2 设备接入模型重构(epic)
**设计定稿:** `docs/superpowers/specs/2026-07-09-device-model-redesign-design.md`。把"设备持久态"扩成一次接入模型重构:device token 自注册(SDK 自生成 id)、`groups→projects` 改名、删 client-login/clients/client_groups。设备 project **继承 device token**(建时勾定,天然绑定,不自报能力)。在线态走 Redis 热 + PG(`devices`)冷持久。
**子项(各自独立 spec/PR):**
- **2a** ✅ rename `groups→projects`(纯机械,先做,后续全用新名)。
- **2b** ✅ device token:`device_tokens` + `device_token_projects` + CRUD + 在线设备数。独立无依赖。
- **2c** 设备自注册 + 删 client-login(WS 网关改 device-token 鉴权 + 自生成 id → upsert `devices` + presence;删 `clients`/`client_groups`/client-login;改 RBAC/seed/smoke)。**最大一块。**
- **2d** 设备持久态:stale 扫描 worker + 列表/详情 API(`read/device`)+ platform/ip/extra 落齐(并入原 #11)+ `status` 口径。
**解锁:** #3(device 日聚合)、#8。

### ⬜ #3 指标聚合体系
**现状(已核实):** `metrics.service` 43 行,全是查询时现扫 `request_logs`;`device_daily`/`rpc_daily` 聚合表未建,`metrics` 表空壳。
**要做:** 两张日聚合表 + worker 累加写入(complete/rpc_metric/device_metric)+ 重启对账(从 request_logs 重灌最近 N 天)+ 周/趋势/GroupSummary 派生 + 聚合表按天清理(留 30 天,承接 #1 暂缓项)。
**依赖:** #2(设备聚合口径)。

### ⬜ #4 maxInFlight 在途并发限流
**现状:** 未做。设备在线数不限,但单设备同时在途任务数无上限,高并发下会压垮单机(轮询摊得均也没用)。
**要做:** client login 收 `maxInFlight`(夹取 [256,1024])+ WS 单设备在途计数上限,满则 `rejected`/429。
**解锁:** #10 的 `rejected` 状态。

## WS 协议健壮性

### ⬜ #5 服务端主动 ping + 读超时
现在纯靠客户端心跳 + Redis presence TTL。补:服务端 ping(5s)+ 读超时(20s)判离线。

### ⬜ #6 帧限制 + deadline
单帧 4 MiB 上限、收到分片帧(FIN=0)直接断、`job.deadlineAt` 过期任务丢弃。均未做。

## 账户 / 分组管理

### ⬜ #7 用户 enabled + last_login_at
用户 `enabled`(禁用登录)+ `last_login_at`(登录更新)。(`can_rpc` 已被 RBAC 取代,算演进。)

### ⬜ #8 分组 enabled + GroupInfo
分组 `enabled`(启停,登录/派发校验)+ GroupInfo 派生统计(设备数/在线数/近7天请求/成功率/运行态 disabled·no_device·online·stale·offline)。
**依赖:** #2、#3。

## 小项

### ⬜ #9 监控筛选下拉选项
从日志去重取 group/action/client 供 UI 下拉,且要求实体仍存在。

### ⬜ #10 rpc 状态细分 `rejected`
**现状(已核实):** 已有 `ok/error/timeout/no_group/no_device/offline/unavailable`。只差 `rejected`(429 队列满/组饱和),**依赖 #4**。

### 🔀 #11 → 并入 2d
platform/extra 落库随设备接入重构一起做(见 2d);client-login 本身被删,改为设备自注册时落。
